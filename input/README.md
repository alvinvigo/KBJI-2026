Letakkan PDF sumber KBJI 2026 di folder ini. PDF tidak disertakan dalam distribusi kode.

Nama berkas bebas: pemeriksaan memakai SHA-256, bukan nama berkas. Fingerprint sumber yang
telah diuji tercatat pada `config/kbji_2026.json` sebagai `source_sha256`.

Jalankan ekstraksi dengan menunjuk berkasnya lewat `--pdf`, misalnya:

    python kbji.py extract --pdf "input/klasifikasi-baku-jabatan-indonesia--kbji--2026.pdf" --out output_baru
